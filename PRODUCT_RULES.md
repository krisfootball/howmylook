# HowMyLook product rules

## Locked decisions

### Account and unlock flow
1. User must create an account first
2. User must log in first
3. User chooses username after signup
4. User must rate 5 photos before accessing any other app actions

## Before unlock, user may only:
- sign up
- sign in
- choose username
- rate photos

## Before unlock, user may not:
- access profile
- create posts
- access following feed
- use other account actions

## Product intent
This rule is core to the app. It forces reciprocity so every user helps rate other looks before asking for attention on their own content.
